MobileTrainer 🏋️
Мобильное приложение для тренировок с использованием искусственного интеллекта для анализа техники выполнения упражнений.

📱 О приложении
MobileTrainer - это интеллектуальный помощник для тренировок, который использует компьютерное зрение и нейросети для анализа правильности выполнения упражнений. Приложение помогает отслеживать прогресс, увеличивать нагрузку и соблюдать правильную технику.

Ключевые возможности:
🤖 AI-анализ техники выполнения упражнений в реальном времени

📊 Отслеживание прогресса с личным кабинетом

🎯 Автоматическое увеличение целей (на 2.5 × от исходного максимума)

📅 Еженедельное обновление максимальных показателей

💪 Поддержка 4 упражнений: отжимания, подтягивания, пресс, приседания

🛠 Технологический стек
Основные библиотеки:
Python 3.11+ - основной язык программирования

Kivy 2.3.1 - фреймворк для создания графического интерфейса

TensorFlow 2.13.0 - глубокое обучение и нейросети

OpenCV - компьютерное зрение и обработка видео

scikit-learn - машинное обучение и нормализация данных

MediaPipe - детекция позы человека

Joblib - сериализация моделей

NumPy - научные вычисления

Matplotlib - визуализация данных

Инструменты разработки:
kagglehub - загрузка датасетов

tqdm - прогресс-бары

h5py - работа с HDF5 файлами

📦 Установка
1. Клонирование репозитория
bash
git clone https://github.com/yourusername/MobileTrainer.git
cd MobileTrainer
2. Создание виртуального окружения
bash
python -m venv trainer_env
# Активация на Windows
trainer_env\Scripts\activate
# Активация на Linux/Mac
source trainer_env/bin/activate
3. Установка зависимостей
bash
pip install -r requirements.txt
4. Установка дополнительных зависимостей
bash
pip install tensorflow==2.13.0
pip install protobuf==3.20.3
pip install mediapipe==0.10.7
pip install opencv-python
pip install scikit-learn
pip install matplotlib
pip install tqdm
pip install joblib
pip install kagglehub
🚀 Запуск приложения
bash
python main.py

🎮 Использование
Первый запуск:
При первом запуске приложение проверит, прошла ли неделя с последнего обновления

Если нужно обновить максимумы, появится экран ввода ваших максимальных показателей

Введите количество повторений, которое вы можете сделать сейчас

Эти значения будут использоваться как базовые для расчета целей

Основные экраны:
📊 Экран прогресса
Отображает текущие значения по каждому упражнению

Показывает цели и прогресс выполнения

Кнопка "УВЕЛИЧИТЬ ЦЕЛЬ" добавляет 2.5 × от исходного максимума

Прогресс-бары визуализируют достижения

🎯 Цель

Счетчик повторений

Предупреждения о неправильном упражнении

Анимация при каждом повторении

Еженедельное обновление:
Каждые 7 дней приложение автоматически предлагает обновить максимальные показатели

Новые значения сохраняются как исходный максимум для будущих расчетов

Текущие цели при этом не сбрасываются

🤖 Модели ИИ
Доступные модели:
push_up_model.keras - анализ отжиманий

pull_up_model.keras - анализ подтягиваний

press_model.keras - анализ пресса

squat_model.keras - анализ приседаний

Загрузка моделей:
Модели автоматически загружаются при запуске приложения. Если возникают проблемы с совместимостью версий, используйте встроенную функцию конвертации моделей.

🔧 Настройка
Конвертация моделей:
Если модель не загружается из-за несовместимости версий TensorFlow:

В главном меню выберите "Конвертировать модели"

Выберите модель для конвертации

Перезапустите приложение

Настройка целей:
Цели автоматически увеличиваются при нажатии кнопки "УВЕЛИЧИТЬ ЦЕЛЬ"

Увеличение происходит на 2.5 × от исходного максимума

Исходный максимум обновляется раз в неделю
